# 苏州中考英语作文批改平台

一个给初三英语教师自用的本地作文批改工具。把「上传 → 批改 → 复核 → 登分 → 发报告 → 归档」串成一条流水线。

**AI 只出初评，最终成绩以教师复核为准。**

**当前版本：v1.1.0**（更新日志见文末）

---

## 它做什么

- **按苏州中考 25 分制批改**：四大维度（内容 10 / 语言 10 / 结构 3 / 书写 2）、五档细则、硬性扣分规则
- **要点核对**：逐条列出作文题的核心要点有没有写到，漏一个要点降一档是硬规则，判定过程全摊开
- **拍照识别题目**：拍一下试卷上的作文题，自动填入题目、词数要求与核心要点（数量不固定，有几条填几条）
- **整张答题卡也能认**：先定位「书面表达」部分再批改，姓名 / 班级 / 考号连左侧装订线上的竖排信息一起扫
- **教师复核**：每篇可改分、改档次、改评语；复核后成绩才是最终成绩
- **逐句纠错**：三档及以上把每个语言错误都标出来（原文 → 正确写法＋类型＋说明）；四档及以下挑最典型的 3–5 处大错，写进每篇详情、学生报告和档案明细
- **批次管理**：新建后可随时改题目 / 默认班级 / 核心要点
- **一键填写班级**：一个批次混了几个班的卷子时，批量补班级（只补空白 / 整批覆盖）
- **登分表**：姓名、班级、考号直接在表格里输入，回车跳到下一行，一键粘贴进 Excel
- **学生报告**：导出 Word，每人独立一页，含四维得分、要点核对、改进建议、评语，以及为该生改写的优化范文
- **学生档案**：按「班级 ＋ 姓名」跨批次归并，看多次作文的成绩走势
- **档案点开看详情**：历次作文明细里点一行，弹出该篇的四维得分、要点核对、扣分、评语、范文、识别原文与原图

## 特点

| | |
|---|---|
| 依赖 | **零第三方依赖**，只用 Node.js 内置模块 |
| 体积 | 约 0.3 MB（不含数据） |
| 数据 | 全部留在本机，服务只监听 127.0.0.1 |
| 数据安全 | 原子写入（先写临时文件再改名），断电或强退不会写坏记录；每天自动留一份快照，文件万一损坏自动回退并提示 |
| 模型 | 兼容 OpenAI 格式，内置 6 家服务商预设，可自定义 |

## 一、启动

双击文件夹里的 **`启动.command`**（Windows 用 **`启动.bat`**），浏览器会自动打开 `http://127.0.0.1:8787`。

用完在终端窗口按 `Ctrl + C` 停止服务。

> 首次双击若提示无法打开，右键 →「打开」→「仍要打开」即可（macOS 对 .command 文件的安全限制）。

**同一时间只开一个窗口。** 重复双击会开出第二个实例（占用 8788 等端口），两个实例共用同一份数据文件，一边保存可能覆盖另一边。

## 二、换到别的电脑上用

**整个文件夹拷过去就能用**，不需要安装任何依赖，整个文件夹只有 1 MB 左右。

前提只有一条：**那台电脑装了 Node.js**（到 https://nodejs.org 下载 LTS 版装一下即可，装一次就行）。

| 系统 | 双击哪个文件 |
|---|---|
| macOS | `启动.command` |
| Windows | `启动.bat` |

启动脚本会自动到常见位置去找 Node（Homebrew、官方安装包、nvm 等都认），找不到会给出安装提示，不会静默失败。

**会跟着一起过去的东西**（都在 `data/` 文件夹里）：

- 所有批改记录、作文照片、学生姓名档案
- 接口配置，**包括 API Key**

**不想带走的东西，拷之前删掉**：

| 想要的效果 | 怎么做 |
|---|---|
| 只带走软件，不带任何学生数据 | 删掉 `data/uploads/` 里的照片、`data/db.json`、`data/students.json` |
| 不带 API Key（让新电脑自己填） | 打开 `data/settings.json`，把 `"apiKey"` 的值清成空字符串 |
| 完全从零开始 | 整个 `data` 文件夹删掉，首次启动会自动重建 |

**注意**：平台只监听本机 `127.0.0.1`，所以同一局域网的其他设备（手机、别的电脑）访问不到，必须在那台电脑本机打开。如果想让全组老师共用，需要把服务放到一台常开的电脑上并改监听地址——那是另一个做法，需要的话告诉我。

## 三、在新电脑上打不开？按症状对号入座

换电脑时，「运行不起来」几乎都是下面四种情况之一，跟程序本身没关系。启动脚本已经能自动修掉前两种，剩下两种会打印明确的提示。

| 症状 | 原因 | 怎么解决 |
|---|---|---|
| 双击提示「**来自身份不明的开发者**」或「**文件已损坏**」 | 文件是从微信 / AirDrop / 邮件 / 网盘传过来的，macOS 给它打上了「隔离」标记 | 启动脚本会自动移除。若双击根本打不开，见下方终端命令 |
| 双击**没反应**，或用**文本编辑**打开了 | 传输过程丢了「可执行」权限（微信、U 盘、Windows 解压都会） | 启动脚本会自动补上。若双击打不开，见下方终端命令 |
| 平台能打开，但**新建批次 / 保存分数报错**，或者数据明明在却读不出来 | 文件夹放在**桌面 / 文稿 / 下载**里，macOS 隐私保护拦住了读写 | **把整个文件夹拖到个人文件夹下**（访达 › 前往 › 个人），再双击启动。或到 系统设置 › 隐私与安全性 › 文件与文件夹 给「终端」授权 |
| 提示「**没有找到 Node.js**」 | 那台电脑没装 Node | 到 https://nodejs.org 装 LTS 版，装完重新双击 |

### 双击打不开时的万能办法（终端命令）

打开「终端」（聚焦搜索输入 Terminal），把下面这行粘进去回车。**第一次会要求输入电脑密码，输入时不显示字符，正常现象。**

```bash
# 先进入平台文件夹（把路径改成实际位置），再修复并启动
cd ~/Desktop/"作文批改平台（Teacher_Tony）" && chmod +x 启动.command 2>/dev/null; xattr -dr com.apple.quarantine . 2>/dev/null; bash 启动.command
```

这条命令做的事：补执行权限、移除隔离标记、然后启动。只要 Node 装了，一定能跑起来。

### 放在哪里最省事

**放在个人文件夹（`~/`）下最省心**，例如 `~/作文批改平台（Teacher_Tony）`。桌面、文稿、下载这三个目录会被 macOS 特别看管，容易触发授权请求，也容易被 iCloud 同步走（同步出问题会让文件变成「占位文件」，读不出来）。

Windows 上正常放桌面或文档里都行，**只要别放在 `C:\Program Files`、`C:\Windows` 这类系统目录**（那里默认不允许写入）。

## 四、第一次使用：填 API Key

进入「设置」页：

1. **服务商预设**选一个（自动填好接口地址和模型名），或直接手填。
2. **API Key** 粘贴你自己的 Key，点「保存配置」。
3. 点「测试连接」验证是否通。

内置预设：

| 服务商 | 接口地址 | 默认模型 |
|---|---|---|
| **DeepSeek（当前使用）** | `https://api.deepseek.com` | `deepseek-flash` |
| 通义千问（阿里云百炼） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen3-vl-plus` |
| 智谱 GLM-4V | `https://open.bigmodel.cn/api/paas/v4` | `glm-4v-plus` |
| Kimi（月之暗面） | `https://api.moonshot.cn/v1` | `kimi-latest` |
| 豆包（火山方舟） | `https://ark.cn-beijing.volces.com/api/v3` | 填方舟控制台的接入点名称 |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o` |

### DeepSeek 模型名对照（2026-09 官方口径）

平台的 `deepseek-flash` 就是 **DeepSeek-V4.1-Flash**，原生支持图片输入。

| 模型名 | 实际版本 | 图片输入 |
|---|---|---|
| `deepseek-flash` ← **填这个** | DeepSeek-V4.1-Flash | ✓ 支持 |
| `deepseek-v4-flash` | 旧名，请求仍由 V4.1-Flash 承接 | ✓ 支持 |
| `deepseek-v4-flash-vision-exp` | 旧名，同上 | ✓ 支持 |
| `deepseek-v4-pro` | DeepSeek-V4-Pro-0813 | ✗ 不支持 |

平台已内置防护：设置页填了不支持图片的模型名时，输入框下方会立刻标红；万一漏掉，批改失败时也会直接告诉你该改成哪个。

### ⚙️ 思考模式（DeepSeek 专有，很重要）

DeepSeek **默认开启思考模式，且强度为 `high`**。平台已默认帮你**关闭**，原因是：

- 思维链会占用输出额度，`max_tokens` 给小了会导致返回的 JSON 被截断
- **思考模式下 `temperature` 参数不生效**（官方明确：不报错但不生效），平台在开启时会自动不发送该参数
- 批 40 篇会明显变慢

**什么时候该打开**：遇到判定有争议、需要复核的作文，或发现漏要点 / 偏题判定不准时，到「设置 → 思考模式」切到「开启」再单独批那一篇。开启后建议把 `max_tokens` 提到 16384 以上。

> 官方文档：https://api-docs.deepseek.com/zh-cn/guides/thinking_mode

**其他服务商**：请选支持图片理解的模型，名称通常含 `vl` / `vision` / `4v`。
接口地址与模型名若与服务商最新文档不一致，按文档改一下即可，页面上的字段都能改。

## 五、批改流程

**1. 新建批次**（工作台 → 当前批改任务 → ＋新建批次）

- 作文题目：必填
- 批次默认班级：选填。**一个批次里混了几个班的卷子也没关系** —— 每篇按卷面上写的班级记，这里只是「一键填写班级」时的默认值
- 核心要点：填本题的必写要点，几条填几条 —— **这栏最重要**，AI 靠它判断有没有漏点，漏 1 点就是降一档（4–5 分）

**改批次**：建好之后想改题目、默认班级或要点，点「当前批改任务」右边的「**编辑批次**」，改完点「保存修改」。改这些**不会动已经批改出来的成绩**，也不会改每篇作文上记的班级。

**📷 拍照识别题目与要点（省打字，也不容易漏点）**

手上有试卷就直接拍，不用一个字一个字敲：

1. 点「拍照识别题目」那块区域选图片，或者**把图片拖进去**，或者**直接按 ⌘V 粘贴截图**（从 PDF 里截作文题最快）
2. 等几秒，题目和要点会自动填进下面的表单
3. 核对识别结果，改掉不对的地方，再点「创建批次」

识别内容除了题目和要点，还会告诉你词数要求和文体，方便你确认。像这样：

```
题目：Give new life to old things
中文题干：给旧物新的生命
要求：词数 100 词左右　·　文体 记叙文
识别到 3 个要点：
  1. 旧物的名称与来历 (name and origin of the old thing)
  2. 焕新的原因与方式 (reasons and ways to give it new life)
  3. 你的感受或收获 (your feelings or gains)
```

几点注意：

- 识别出错或没配 Key 时，会直接告诉你原因，**手动输入照样能用**，不影响后续批改
- 要点数量不固定：识别到几条就填进几条，可以点「＋ 加一条」或某条的「删除」手动增删
- 识别用的是和阅卷**分开的**一套提示词，改阅卷提示词不会影响识别效果
- 识别的照片不会被保存，只是当场读一次

**2. 上传照片**：点击或拖拽，可一次多张。一张照片 ＝ 一篇作文，建议一页一拍。

- 上传前会把图片压到长边 1800px 再发出去，省流量也够识别
- 照片可以按「编号_姓名.jpg」命名（如 `01_蔡子成.jpg`），姓名会自动填好，省一道手
- 建议用手机相册的涂鸦功能把学生姓名涂掉，从源头避免个人信息泄露

**3. 点「开始批改」**：按顺序逐篇处理，进度条实时显示，结果卡片即时出现。

**4. 教师复核**：每篇点「教师复核 / 修改」，可改得分、档次、四维度分值、扣分项、核心问题、建议、评语。

- 复核过的记录会标「教师已复核」，导出成绩表时以复核结果为准
- 想恢复成 AI 原评，点「撤回为 AI 原评」

**逐句纠错**：批改结果里多了一栏「逐句纠错」——**三档及以上**会把这篇作文的每个语言错误都列出来（原文 → 正确写法＋错误类型＋一句话说明）；**四档及以下**错误太多，只挑最典型、最影响理解的 3–5 处大错。学生报告（Word）和「学生档案 → 点开某篇」里也都会带出来。

**5. 学生信息与作文标识（登分用）**

批改时 AI 会顺带做两件事，不用你额外操作：

**① 认卷面上的学生信息。** 学生写在纸上（或答题卡装订线上）的姓名、班级、考号/学号会被自动提取录入。

- **文件名里带姓名就直接用**：把照片按「编号_姓名.jpg」命名，上传时姓名就填好了，来源标「文件名」。这是你自己排的名单，比认卷面上旋转的小字可靠。
- **写了就自动录入**，来源标「卷面识别」。注意答题卡上的姓名不一定在卷首：很多学校是**竖排（字旋转 90°）印在左侧装订线上**，标着「班级 / 姓名 / 考场 / 座次」，平台会连这四处一起扫。
- **没写就留空**，显示「待补填」，编号照常用 —— 不猜、不编
- 识别错了或没写，在每篇详情里手填姓名/班级/考号，点「保存」，来源变成「教师填写」
- **手填的不会被后续重新批改覆盖**（AI 识别优先让位于你填的；用了文件名的，重新批改也不会把姓名改掉）

**一键填写班级**（在「记录与统计 → 登分表」上方）：一个批次里混了几个班的卷子、或者几篇没认出来班级时，在这里输入班级名，按需点两个按钮之一：

| 按钮 | 作用 |
|---|---|
| **只填空白的** | 只补那些还没填班级的，已经识别出来的不动（日常最常用） |
| **全部改成这个** | 把这一批每一篇的班级都改成它（整批重登时用） |

填完班级立刻生效，学生档案的归并方式也跟着更新。班级名有历史记忆 —— 输入框点一下就能选以前的班名，不用重打。

**② 提取作文标识。** 每篇会记下学生自己写的**标题**和**正文第一句**，方便你在一堆卷子里快速认出是哪一篇。模型没给出来时，系统会从识别原文里自动提取。

这些信息**只存在本机**。姓名会自动同步到**成绩表**和**学生报告**上；没有姓名就留空（报告上留一条空白下划线给你手写）。

**6. 生成范文**（结果区右上角「生成范文」）

点一次会给**所有还没范文的作文**逐篇生成「适配这个学生水平」的优化范文。每篇约十几秒。

范文的要求已写死在提示词里，保证它真的能用：

- 覆盖题目全部核心要点，一个不少
- 标准三段式 + 自然过渡词，80–120 词
- **词汇句式不超纲**，只比该生现有水平略高，绝不写成满分范文（那样学生模仿不来）
- 尽量保留学生原文里真实的细节，读起来像他自己写得出来的
- 不出现真实姓名、校名

每篇范文还会附带：**「为什么这样改」** 2 条修改说明，和 **「背下来能加分的好词好句」** 3–5 条。

生成后可直接在「教师复核」里改范文，改完会一起保存。

**7. 导出学生报告**（结果区或记录页的「导出学生报告」）

生成一个 Word 文档，**每个学生一页，可直接打印**，裁开发到学生手上。每页内容：

```
英语作文批改报告        编号：1 号   姓名：李思远
作文题目：Give new life to old things
得分：19 / 25    档次：二档（良好）
内容 8/10   语言 7/10   结构 2/3   书写 2/2   词数 96
一、写作要点核对
   【已写】旧物的名称与来历 —— 写了旧自行车，但没交代来历
   【已写】焕新的原因与方式 —— 方式写得较清楚
   【漏写】你的感受或收获 —— 全文未写感受
二、需要改进的地方
三、怎么提高
四、AI 评语（教师复核过的篇目这里会写成「老师评语」）
五、为你改写的范文（照着读三遍，把好句子抄下来）
   为什么这样改：
   背下来能加分的好词好句：
```

几点说明：

- **姓名会自动印上**：卷面识别到的、或你在每篇详情里手填的，都会印在这行上。没有姓名时显示 `姓名：______`，留空给你手写。
- 未批改的篇目、和批改结果为空的那几篇，**不会进报告**
- 如果还有作文没生成范文，导出时会提醒你，那些页的范文位置会显示占位提示
- 导出前建议先点「生成范文」，报告才完整
- **报告含学生姓名，请勿转发到外部平台**；打印出来发给学生本人没问题

## 六、成绩表与统计

「记录与统计」页可看：

- 历史批次列表，点任意一条查看明细
- 班级平均分、最高分、最低分、复核进度
- 五档分布条形图
- **班级整体情况分析**：四维平均分（一眼看出全班弱在内容、语言还是结构）、每个要点的漏写率（哪条没教透）、常见错误类型（从逐句纠错里聚合）、词数超标提醒（哪些会吃硬性扣分）
- **AI 共性分析与教学建议**：点一下「生成班级共性分析」，由模型把全班数据综合成「做得好、共性存在的问题、下一阶段教学建议」三段，直接给老师上课用（纯文本，成本很低，生成结果存到批次上可随时重看）
- 成绩明细表，一键**导出学生报告（Word）** 或 **导出成绩表（Excel）**
- **登分表**：专门给你往学校系统里录分用，列出 编号 / 姓名 / 班级 / 考号 / 作文标题 / 正文首句 / 得分 / 档次，一眼能对上人。

**姓名、班级、考号可以直接在登分表里改** —— 点一下单元格就能输入，改完点别处自动保存（右下角闪一下「已存」）。填完一个按**回车**会自动跳到下一行的姓名框，一路填下来很快。

登分表两种用法：

- **复制登分表** —— 复制成表格格式，直接粘贴进 Excel 或学校登分系统，不会串列
- **导出登分表（含姓名）** —— 生成 CSV，文件名已标注「仅内部使用」

> ⚠️ **导出的四份文件——成绩表、登分表、学生报告、成绩归档表——都会带上姓名**（卷面识别到或你在登分表里填的；没识别到就留空）。
> 这些文件含学生个人信息，仅供你内部使用或发给学生本人，**请勿转发或上传到任何外部平台**。

导出的 CSV 用 Excel 或 WPS 直接双击打开，中文不会乱码。Word 报告用 WPS 或 Word 打开即可打印。

## 七、学生档案（跨批次看多次成绩）

顶部「学生档案」页，把同一个人在不同批次里的作文成绩归到一起。

**怎么归档的**

按「**班级 + 姓名**」自动匹配。所以：

| 情况 | 结果 |
|---|---|
| 同一个班、同一个姓名，写了两次作文 | 归为同一个学生，看到 2 次成绩 |
| 班名写法有出入（`九(8)班` / `九8班`） | 认成同一个班，不会分成两个 |
| 不同班级的同名同姓 | 是两个人，不会混在一起 |
| 卷面上没写姓名 | **不归档**，等你补了姓名才进来 |

姓名来源还是那两个：卷面识别到的，或你在登分表里手填的。补上姓名后，打开这一页就会自动归档。

**班级以每篇卷面为准。** 批次里填的班级只是个默认值，不会顶替学生本人的班级 —— 所以一个批次里混了几个班的卷子也能正确归班；哪篇没认出来，用登分表的「一键填写班级」补齐即可。

**能看什么**

- **班级概览**：每个班多少学生、多少篇作文、平均分、还有几篇没归名
- **学生名单**：每人作文次数、平均分、最高、最低、最近一次成绩，以及**较上一次是升还是降**
- **点开某个学生**：成绩走势柱状图、同班其他同学的平均分对照、历次作文明细（日期 / 题目 / 本批编号 / 得分 / 档次）
- **历次明细里点任意一行**，会弹出那一篇的**完整批改信息**：四维得分、要点核对、硬性扣分、核心问题、改进建议、评语、优化范文、识别原文，以及原始照片（点图片可再放大）。翻旧账、找学生讲评时直接从这里看，不用回工作台翻。

**改错了怎么办**

在某个学生的详情页里可以直接改姓名、班级、学号，点「保存并同步到所有作文」—— 这名学生**已有的所有记录会一起更新**。改完如果和另一个学生重名同班，两人会自动合并。

**导出成绩归档表**

「导出成绩归档表（CSV）」生成一张**学生 × 各次作文**的矩阵表，一眼看完一个班的历次成绩。适合期末统计。

> 这张表含学生姓名，文件名标了「仅内部使用」，请勿转发。

## 八、数据与隐私

| 内容 | 位置 |
|---|---|
| 作文照片 | `data/uploads/` |
| 批改记录 | `data/db.json` |
| 学生档案 | `data/students.json` |
| 接口配置与 Key | `data/settings.json` |
| 阅卷提示词 | `data/prompt.txt` |
| 自动快照 | `data/backup/`（每次启动 + 每次删批次前各一份，最多 10 份） |

- 服务只监听本机 `127.0.0.1`，同一局域网的其他设备也访问不到
- **同一时间只开一个平台窗口**：多个实例共用同一份数据文件，可能互相覆盖
- 记录采用原子写入，断电或强退不会写坏数据文件；万一损坏，启动时自动回退最近快照并提示
- 只有点「开始批改」时才把当篇作文照片发给你配置的 AI 服务商，其余时间不联网
- **导出的成绩表、登分表、学生报告、成绩归档表都会带上姓名**（卷面识别到或你手填的；没有则留空）。这些文件含学生个人信息，仅供内部使用或发给学生本人，请勿转发到外部平台
- **备份**：整个 `data` 文件夹复制走即可，换电脑装回原位置就能继续用

**如果你是拷走这个项目的人**：`data/` 目录里是真实的批改记录、学生姓名和作文照片，属于未成年人个人信息，已通过 `.gitignore` 排除，不会跟着仓库过来，首次启动会自动创建空目录。

**如果你要基于自己的使用记录提交代码**：请先把 `data/` 排除干净。把姓名改成「学生A」是不够的——作文照片上学生自己手写的名字还在。

## 九、常见问题

**拍照识别题目失败 / 识别不准**
可以取消勾选重拍一张更清楚的照片；识别失败不影响使用，直接手动输入题目和要点即可。若提示未配置 Key，到「设置」填好 Key 再重试。

**批改失败，提示「当前模型不支持图片输入」**
模型名填成了纯文本模型。DeepSeek 改成 `deepseek-flash`；通义千问用 `qwen3-vl-plus`；智谱用 `glm-4v-plus`。改完点「保存配置」再重试。

**批改失败，提示 401 / 403**
Key 填错、过期或没充值。到服务商控制台确认 Key 有效、额度充足。

**提示「输出被长度限制截断」**
把「设置」里的 `max_tokens` 调大。若开着思考模式，思维链会吃掉大量输出额度，建议直接提到 16384 以上，或把思考模式改成「关闭」。

**某几篇显示「疑似空结果」或「批改失败」**
模型偶发故障（返回空模板）。平台会把它标出来而不是当成 0 分。点结果区右上角「重批未成功的 N 篇」一次性补完，或单独点那一篇的「重新批改」。统计和导出的成绩表都会自动跳过这些篇目，不会被假的 0 分拉低平均分。

**为什么会有空结果**
DeepSeek 的 JSON 输出模式官方承认「有概率返回空的 content」。平台的应对是：一旦检出空结果，自动换一种模式重试一次；两次都空就标为失败并保留模型原始返回，方便排查。

**提示「模型返回了空内容」**
同上，平台会自动重试一次。若仍失败，可到「设置」关掉「强制 JSON 输出模式」再试。

**批改一篇要等多久**
关闭思考模式时一般十几秒一篇；开启思考模式会明显变慢，批量阅卷不建议开。

**提示「AI 未返回标准 JSON」**
换一个模型，或关掉强制 JSON 模式。

**学生姓名 / 班级识别不出来**
答题卡上的姓名不一定在卷首，很多是**竖排印在左侧装订线**上（标着班级 / 姓名 / 考场 / 座次），平台会连这四处一起扫。还是没认出来的话有两条路：把照片按「编号_姓名.jpg」命名重新上传（姓名会自动带出），或者在「记录与统计 → 登分表」里手填、或用「一键填写班级」批量补。

**分数偏高 / 偏严**
到「设置」页改「阅卷提示词」。里面就是完整的苏州中考 25 分制标准，想加要求直接写进去，改坏了点「恢复内置默认」即可。

**报告里四个维度加起来，和总分不一样**
这是 AI 偶尔犯的口径错误：它先算出内容＋语言＋结构＋书写，又把硬性扣分从总分上单独减了一次。
平台不替你改分（成绩以你的复核为准），但会：在每篇详情、登分表、成绩明细里标出「得分待核」；在导出的学生报告里补一行「四维合计 13 分，硬性扣分 1 分，最终得分 12 分」，让学生自己也算得通；导出成绩表新增「四维合计」列，方便一眼核对。
要改分数，点那一篇的「教师复核 / 修改」——表单下面会实时显示四维合计与总分对不对得上。
提示词里已经加了「得分口径 · 必须自洽」一条，之后新批的作文默认不会再出现这种情况。

**会不会丢数据 / 断电了怎么办**
记录每次都是「原子写入」：先写一个临时文件，写完再改名覆盖。所以哪怕中途断电、强退、按 Ctrl+C，`db.json` 要么是改动前的完整内容，要么是改动后的完整内容，不会出现写了一半的半个文件。
另外平台会自动留快照：每次启动留一份当天的，每次删批次前再留一份，放在 `data/backup/`，最多保留 10 份。
万一数据文件真的损坏（例如硬盘出错），下次启动会自动用最近的快照恢复，并弹窗告诉你恢复了什么；损坏的原文件会改名成 `db.json.corrupt-时间.json` 留在原地备查。
想手动备份，直接把整个 `data/` 文件夹复制走即可；想换电脑，把 `data/` 拷到新机器同一个位置就行。

**要点核对怎么看**
每篇详情里有一栏「要点核对」，逐条列出达标情况：`✓` 表示已写，`✗` 表示漏写，后面还会说明覆盖到什么程度（例如「写了旧自行车，但没交代来历」）。漏了几个、因此降了几档，一眼就能看到。这栏直接支撑「要点第一」的判定，也是你和学生讲评时最好用的依据。

**要不要让 AI 写范文**
「设置」里有一项「让 AI 同时生成适配水平优化范文」，默认关闭。开启后每篇会多输出一段约 100 词的范文，批改变慢、费用增加。批量阅卷建议关；要给学生做示范或写讲评时再开。生成的范文可在「教师复核」里直接改，改完会跟着记录一起保存。

**想换一个 API Key / 清掉 Key**
在「设置」页粘贴新 Key 保存即可覆盖；点「清除已保存的 Key」可以彻底清掉。

**不要同时开两个平台窗口**
会各自占一个端口（8787、8788…），但**共用同一份数据文件**。两个窗口都开着时，一边保存可能把另一边刚存的内容覆盖掉。用完一个先关掉（终端按 Ctrl + C）再开下一个。

**服务起不来，提示端口被占用**
会自动往后找端口（8788、8789…），看终端里打印的「访问地址」按那个开。

**想换端口**
终端里这样启动：`PORT=9000 ./启动.command`

**删批次时提示「有照片文件未能删除」**
记录已删掉，但磁盘上的照片没清干净。按提示打开 `data/uploads` 手动删除，避免学生信息残留在本机。

- **逐句纠错**：三档及以上逐条标注全部语言错误，四档及以下挑最典型的 3–5 处大错；写进批改详情、学生报告和档案明细。
