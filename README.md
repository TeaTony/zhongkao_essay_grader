# 苏州中考英语作文批改平台

一个给初三英语教师自用的本地作文批改工具。把「上传 → 批改 → 复核 → 登分 → 发报告 → 归档」串成一条流水线。

**AI 只出初评，最终成绩以教师复核为准。**

## 它做什么

- **按苏州中考 25 分制批改**：四大维度（内容 10 / 语言 10 / 结构 3 / 书写 2）、五档细则、硬性扣分规则
- **要点核对**：逐条列出作文题的核心要点有没有写到，漏一个要点降一档是硬规则，判定过程全摊开
- **拍照识别题目**：拍一下试卷上的作文题，自动填入题目、词数要求与 3 个核心要点
- **教师复核**：每篇可改分、改档次、改评语；复核后成绩才是最终成绩
- **登分表**：姓名、班级、考号直接在表格里输入，回车跳到下一行，一键粘贴进 Excel
- **学生报告**：导出 Word，每人独立一页，含四维得分、要点核对、改进建议、评语，以及为该生改写的优化范文
- **学生档案**：按「班级 ＋ 姓名」跨批次归并，看多次作文的成绩走势

## 特点

| | |
|---|---|
| 依赖 | **零第三方依赖**，只用 Node.js 内置模块 |
| 体积 | 约 0.3 MB（不含数据） |
| 数据 | 全部留在本机，服务只监听 127.0.0.1 |
| 模型 | 兼容 OpenAI 格式，内置 6 家服务商预设，可自定义 |

## 怎么跑

前提只有一个：电脑装了 [Node.js](https://nodejs.org)。

| 系统 | 双击 |
|---|---|
| macOS | `启动.command` |
| Windows | `启动.bat` |

启动脚本会自检：补执行权限、移除 macOS 隔离标记、检查数据目录可写、查找 Node.js。任一步出问题都会打印明确的解决办法，不会静默失败。

首次使用需要在「设置」页填入你自己的模型 API Key。

## ⚠️ 关于数据

`data/` 目录里是**真实的批改记录、学生姓名和作文照片**，属于未成年人个人信息，已通过 `.gitignore` 排除。

**如果你 fork 或克隆这个仓库**：不用担心，`data/` 不会跟着过来，首次启动会自动创建空目录。

**如果你要基于自己的使用记录提交**：请先把 `data/` 排除干净。把姓名改成「学生A」是不够的 —— 作文照片上学生自己手写的名字还在。

## 目录结构

```
├── server.js            本地服务（22 个接口 + DOCX 生成器）
├── public/              前端界面
│   ├── index.html
│   ├── styles.css
│   └── app.js
├── 启动.command          macOS 启动脚本
├── 启动.bat              Windows 启动脚本
├── 使用说明.md           完整使用手册
└── data/                运行时数据（不入库，首次启动自动创建）
```

## 说明

- 本工具只监听本机 `127.0.0.1`，局域网内其他设备访问不到。这是隐私设计，不是缺陷。
- 同一时间只开一个窗口；多个实例共用同一份数据文件可能互相覆盖。
- 批改质量最终取决于教师复核，AI 初评不作为最终成绩。
